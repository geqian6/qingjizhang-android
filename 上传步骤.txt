轻记账 · 上传到 GitHub（照着做，一共四步）

第 1 步  让隐藏文件露出来【关键，不然后面会漏文件】
   在这个文件夹窗口里，点最上面那一排的「查看」
   （Win11 是「查看」→「显示」；Win10 是「查看」标签）
   勾上  「隐藏的项目」
   勾完你会看到多出来一个 .github 文件夹 —— 那个必须一起传，它是自动编译的开关。

第 2 步  全选
   在这个文件夹里按 Ctrl + A
   （应该选中 app、.github、build.gradle.kts、settings.gradle.kts、
     gradle.properties、README.md、.gitignore、上传步骤.txt，共 8 项）

第 3 步  拖进网页
   浏览器打开下面这个地址（要已经登录 geqian6 这个账号）：
       https://github.com/geqian6/qingjizhang-android/upload/main
   页面中间会有一个大大的虚线框，写着 Drag files here
   把第 2 步选中的东西直接拖进那个框里
   （注意：拖「文件夹里面的东西」，不要拖「轻记账-上传GitHub」这个文件夹本身）

第 4 步  提交
   等文件全部传完（右上角进度条转完），滚到页面最下面
   点绿色的  Commit changes

传完就完事了。回到仓库点顶部的 Actions 标签页，能看到一个正在跑的编译任务。
大约 4~8 分钟出结果。

--------------------------------------------------
如果传完发现仓库里没有 .github 文件夹（说明第 1 步的隐藏项目没勾）：
   不影响编译之外的任何事，但需要手动补一次 workflow：
   1. 仓库页面点 Actions 标签
   2. 点 set up a workflow yourself
   3. 把 2_build.yml 里的内容整份粘贴进去，把原来的示例代码全部删掉
   4. 右上角 Commit changes
   （2_build.yml 在 E:\workbuddy缓存\2026-10-07-11-42-24\轻记账-上传GitHub\ 里）
