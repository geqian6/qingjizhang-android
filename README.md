# 轻记账 (QingJiZhang)

一个**完全本地**的安卓记账 App。自动记录微信、支付宝的支付流水，按来源分类，提供日 / 周 / 月的收支对比图表。

## 核心特性

- **来源标识**：每笔流水记录来源（微信支付 / 支付宝 / 银行卡 / 现金 / 手动），界面上以品牌色区分
- **自动记账**：读取系统支付通知，自动落账；解析不了的先进「待确认」，由用户补全分类
- **多周期对比**：日 / 周 / 月三个维度切换，收入支出双柱对比 + 分类占比环形图
- **预算与超支提醒**：总预算 + 分类预算，达到 80% 和超支时提醒
- **不联网**：App 不申请网络权限，所有数据存在本机 SQLite

## 构建

本仓库自带 GitHub Actions 工作流，推送代码后自动编译：

```
Actions 标签页 → Build APK → 最新一次运行 → Artifacts → qingjizhang-debug
```

下载得到 `app-debug.apk`，传到手机安装即可。

本地构建（需自行安装 Android Studio）：

```bash
gradle assembleDebug
```

## 关于自动记账的说明

微信与支付宝**没有对个人开放的账单接口**，各家银行也不开放。因此自动记账依赖读取系统通知，这是行业通行的做法，但存在两个客观限制：

1. 微信等应用有动机限制第三方读取其内容，机制可能随版本变化失效，**解析规则因此在数据库中可配置，而非硬编码**
2. 银行卡流水无法自动获取，只能通过导入账单文件或手动补录

因此手动记账是主干功能，自动记账是增强。
